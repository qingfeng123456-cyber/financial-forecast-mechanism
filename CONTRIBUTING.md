# Contributing

Please use a focused pull request and explain which study, evidence file, or
documentation statement changes. Contributions must preserve chronological
data boundaries, test-set separation, adverse results, and study-specific
metrics. Do not replace returned evidence with selectively regenerated output.

Before proposing a change, run `python scripts/static_validate.py`. Runtime
changes should also be checked on an appropriate training host and accompanied
by a complete returned archive.
