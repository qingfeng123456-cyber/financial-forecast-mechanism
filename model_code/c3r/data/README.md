# Data directory

The market panels are intentionally not committed here. Obtain them from the
sources documented in `DATASETS.json`, construct the three `.npz` files with
the recorded schema and hashes, and place them in this directory before
running `python main.py` from the study directory.

The KDD17 and ACL18 research releases include underlying market data whose
redistribution terms are not replaced by this repository's code license.
