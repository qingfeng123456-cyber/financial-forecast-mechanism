# C3R-MoE：AutoDL 完整实验包

当前版本研究两个相互衔接的模块：**接收者条件的残差信息交换**与**通信重算后的组合风险路由**。没有用旧项目结果证明这个新方法，也没有预先声称性能改善。

## 运行

建议使用已有 PyTorch 的 AutoDL GPU 环境。依赖由用户手动安装，程序不安装或升级任何库：

```bash
pip install -r requirements.txt
python main.py
```

数据已随包附带，运行不需要下载数据。每轮主干训练、路由训练和缓存对照训练均打印进度与预计耗时；控制台全文写入 `console.log`。运行后下载终端打印的 `log/RUN-...-C3R.zip`。

## 固定实验矩阵

- 3 个数据集：S&P 500 CC0、KDD17 作者基准、ACL18/StockNet 作者基准。
- 6 个比较模型：GRU，以及 StockMixer、MASTER、MIGA、MERA、MAFS 的明确标注的共同协议适配。
- 4 个完整因子消融：完整模型、只保留交换、只保留风险监督、两个模块均移除。
- 1 个容量相同的未投影消息交换对照。

总计 **33 次主干训练**。完整模型另复用冻结主干缓存训练四种小路由对照：加性评分、普通四专家门控、只删输出的组合路由、静态混合。它们合计 12 次小读出训练，单独记录，不能把它们算作没有训练。消息干预、分年结果、统计分析和绘图均不重新训练主干。

固定小模型、日期抽样、提前停止和冻结缓存用于控制成本，没有搜索、自动重试或按小时强制终止。以 RTX 4090/A100 等 GPU 的 3–8 小时作为规划目标；这是未经本地计时的预算假设，硬件、实际轮数及绘图会影响耗时。完整矩阵最多 152,064 个主干日期步骤，另有路由缓存步骤；AutoDL 会根据已完成任务更新剩余时间。

## 方法与输出

专家先学习自己的预测；发送消息时去除在接收者潜在向量方向上的分量，使用稀疏边、拒收选项和有界残差更新。编码器只计算一次，再分别重算 15 个非空专家组合的通信，另保留不通信的完整参考。路由器使用主干没有拟合或选择过的后段训练日期学习组合的相对排序风险，测试时只看当前可用输入。

输出包括预测、模型、分割信息、训练记录、排名与费用情景指标、共同日期区间、因子交互、缓存对照、分年分析、原始机制样本、来源记录、文件校验和与图表。完整成功时生成 **24 张模块实验图（三个数据集各八张）**，统一为可直接用于 LaTeX 的矢量 PDF；基线比较输出 CSV 和 LaTeX 表格。

每个数据集的八张图对应：双模块因子消融、消息干预与未投影对照、通信和拒收、配对的交换前后 t-SNE 与表示变化、通信重算与只删输出的贡献差异、组合风险与重算影响、路由行为、四种路由消融对照。实验图仅包含模块作用和消融分析，正负效果均保留。`figures/CAPTIONS.md` 和 `figures/latex_includes.tex` 提供图注和插图代码。详见 `research/FIGURE_PLAN.md`；图是否支持模块有效性仍需结合真实结果。

命名基线不是原论文全部数据模态和协议的复现；详情见 `research/DATA_AND_BASELINES.md`。S&P 面板存在生存者选择，作者数据的基础行情权利未推断为可公开再分发。经济结果是固定交易费用的研究情景，不含借券和冲击成本估计。

本地仅做静态验证。张量、梯度、组合不变性与时间分割检查只在 AutoDL 执行。任何失败均保留并使正式完成标记为 false。
