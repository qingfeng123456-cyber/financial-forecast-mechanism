# DARC AutoDL package

Run `python main.py` from this directory after the packages in `requirements.txt` are present in the AutoDL environment. The program does not install dependencies. The three public research panels are bundled under `data/`; `DATASETS.json` records provenance and hashes. An interrupted or failed run still writes a `log/RUN-...-DARC.zip` evidence bundle with the failure record. Download that ZIP for analysis. A completed run has `formal_experiment_completed: true` in `STATUS.json`.

The registered design trains six forecasters per dataset, 18 backbone fits in total. The GRU is a generic control; StockMixer, MASTER, MIGA, MERA and MAFS are **common-protocol adaptations**, not claimed original-author reproductions. Once trained, their frozen out-of-sample forecast streams feed eight cheap readouts. Four readouts form the mechanism factorial: global weights / pair-specific arbitration, each with the matured-advantage gate off / on. Equal-rank, static calibration weights, simple recent performance and uniform soft pairwise voting are additional readout controls. No search, automatic retry, or wall-clock kill is used.

The mechanism acts only on forecasts available at a decision origin. Historical expert accuracy and rank-list advantage enter the ledger after the configured return window has completed. The calibration window precedes live router evaluation; later router, validation and test origins are processed chronologically. The test cross-section is selected from available feature history, never from future-label presence. All completed, failed and adverse results are retained. The 24 PDFs are descriptive module-effect and factorial figures, eight per dataset; baseline comparisons are CSV tables. Figures alone do not establish improved prediction.

The package has had **static-only local validation**. No local model forward, training, smoke test, backtest or empirical evaluation was run. Runtime and data checks execute on the AutoDL host when `python main.py` runs. The actual runtime depends on GPU and data throughput; there is no guaranteed ten-hour completion time.
