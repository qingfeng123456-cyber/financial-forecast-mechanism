# Manuscript sources

`main.tex` is the anonymous CREBSS manuscript and `supplement.tex` is its
separate supplement. The official `crebss.cls`, all referenced figures, the
bibliography, compact evidence tables, and compiled PDFs are kept together so
the paper can be inspected without reconstructing files from the private
research archive. Generated TeX scratch files are excluded.

A public repository can reveal the owner account during double-blind review.
Authors should follow the editor's instructions when deciding whether to cite
the live repository in the anonymous manuscript or disclose it only to the
editorial office.
